# Ping监控系统 - 登录功能说明

## 新增功能

本次更新添加了用户登录和认证功能：

### 1. 首次访问
- 系统首次启动时，没有管理员账户
- 访问系统会自动跳转到初始化页面 `/init`
- 需要设置管理员用户名和密码：
  - 用户名：至少3个字符
  - 密码：至少6个字符

### 2. 后续登录
- 完成初始化后，系统会跳转到登录页面
- 使用设置的用户名和密码登录
- 登录成功后会保存认证令牌，7天内免登录

### 3. 退出登录
- 点击页面右上角的"退出登录"按钮
- 退出后会清除令牌并跳转到登录页

## 技术实现

### 后端
- 使用 JWT (JSON Web Token) 进行认证
- 密码使用 bcrypt 加密存储
- 所有业务API都需要认证才能访问

### 前端
- 使用 Vue Router 进行路由管理
- 实现路由守卫，未登录自动跳转
- Token 存储在 localStorage 中

## 启动步骤

1. 安装后端依赖：
```bash
cd backend
pip install python-jose[cryptography]==3.3.0 passlib[bcrypt]==1.7.4
```

2. 安装前端依赖：
```bash
cd frontend
npm install
```

3. 启动服务（使用项目根目录的 start.bat）

4. 访问 http://localhost:5173
   - 首次访问会跳转到初始化页面
   - 设置管理员账户
   - 登录系统

## 注意事项

- 请妥善保管管理员密码
- Token默认7天过期，过期后需要重新登录
- 数据库文件中存储了用户信息，请勿删除
